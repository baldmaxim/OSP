# UI: правила типографики и таблиц

Ориентир — GitHub Primer Product UI: рабочий интерфейс с плотными таблицами,
в приоритете читаемость, компактность и предсказуемость. Brand-стили,
градиенты, декоративные карточки и крупные тени не используем.

**Этап 1 (сейчас):** правила действуют только в разделе «ВОРы и РД»
(`src/pages/VorsPage.jsx`, стили `src/pages/VorsTypography.css`). Остальной
портал пока на прежней типографике; переносить правила в другие разделы —
отдельными шагами, тем же способом (класс-обёртка раздела + свой CSS-файл).

## Шрифт

- **Inter 4.1** из официального релиза https://github.com/rsms/inter, лицензия
  SIL OFL 1.1 — `public/fonts/inter/LICENSE.txt`.
- Файлы отдаёт само приложение: `public/fonts/inter/`, внешний CDN не нужен.
  `@font-face` — `src/styles/fonts.css`.
- Только нужные начертания: **400** (текст), **500** (кнопки, фильтры,
  заголовки колонок), **600** (заголовок раздела). Курсив и другие веса не грузим.
- Семейство называется **`Inter OSP`** — не `Inter`: `index.html` пока
  подгружает `Inter` с Google Fonts, одноимённые `@font-face` смешались бы.
  Имя в `@font-face` и в `--vr-font` должно совпадать.
- Резервный стек: `'Segoe UI', system-ui, -apple-system, 'Helvetica Neue', Arial, sans-serif`.

## Шкала (токены `--vr-*` в `VorsTypography.css`)

| Роль | Размер / интерлиньяж | Вес | Токены |
|---|---|---|---|
| Основной текст, ячейки таблицы | 14/20 px (0.875 / 1.25 rem) | 400 | `--vr-text`, `--vr-text-lh` |
| Кнопки, фильтры, вкладки | 14/20 px | 500 | `--vr-text`, `--vr-medium` |
| Заголовки колонок | 13/18 px (0.8125 / 1.125 rem) | 500 | `--vr-th`, `--vr-th-lh` |
| Пояснения, счётчики, мелкие действия в строке | 12/16 px (0.75 / 1 rem) | 400 (действия — 500) | `--vr-hint`, `--vr-hint-lh` |
| Заголовок раздела | 20/28 px (1.25 / 1.75 rem) | 600 | `--vr-title`, `--vr-title-lh` |

- Размеры — только в `rem`. Базовый размер шрифта браузера (`html { font-size }`)
  не переопределяем: пользователь, увеличивший шрифт в браузере, должен получить
  увеличенный интерфейс.
- Новых размеров «между» ступенями не вводить; нужен иной акцент — вес 500/600
  или цвет из существующих токенов (`--text-primary/-secondary/-tertiary`).

## Таблицы

- **Заголовки колонок — обычным регистром**, без `text-transform: uppercase` и
  разрядки. Аббревиатуры (ВОР, РД, СТО, ДС, КП) пишутся прописными в самом тексте.
- **Цифры моноширинные** (`font-variant-numeric: tabular-nums`) — даты, номера,
  суммы, счётчики.
- **ФИО в ячейке — «Фамилия И. О.»** (`shortPersonName` из `src/utils/personName.js`),
  полное ФИО — в `title`. Поиск, фильтры и выгрузка работают по **полному** значению.
- **Длинное описание** можно сокращать до 2–3 строк только если полный текст
  доступен: подсказка `title` и/или переход в карточку/окно.
- **Высоту строк не фиксировать** — многострочное содержимое растягивает строку.
- **Пустые значения** — словом («Не назначен», «Не указано»), без декоративных
  тире и курсива. **Отсутствие ответственного у активной записи не маскировать** —
  метка `.vor-resp-empty.is-alert` (жёлтая, `--warning-*`).
- **Ширина:** на широком окне (≥1700 px) — доли колонок через `<colgroup>` +
  `table-layout: fixed`, таблица без горизонтального ползунка. На окнах уже —
  авто-раскладка с прокруткой таблицы, у колонок минимальная ширина, чтобы
  ничего не сжималось до нечитаемого (обрезка дат посреди цифр хуже прокрутки).

## Поля, кнопки, фокус

- `button`, `input`, `select`, `textarea` наследуют шрифт (`font-family: inherit`) —
  иначе `select` рисуется Arial.
- Видимый фокус с клавиатуры: `outline: 2px solid var(--primary-color); outline-offset: 2px`
  для `:focus-visible`.
- Контраст текста — не ниже 4,5:1. `--text-tertiary` на сером фоне
  (`--bg-tertiary`) даёт ~4,3:1 — для заголовков колонок и вкладок используем
  `--text-secondary`.

## Всплывающие элементы

Списки фильтров (`FilterDropdown`) и окошко срока (`DateRangeCell`) рисуются
порталом в `<body>` — вне обёртки раздела. Раздел ставит на `<body>` класс
`vors-typography`, пока открыт; правила для порталов пишутся под
`body.vors-typography`.

## Откат этапа 1

1. Убрать из `src/pages/VorsPage.jsx` импорты `../styles/fonts.css` и `./VorsTypography.css`.
2. По желанию удалить `src/pages/VorsTypography.css`, `src/styles/fonts.css`,
   `public/fonts/inter/`. Классы `vors-page` / `vors-typography` без этих
   стилей ничего не делают.

Разметочные правки раздела (ФИО «Фамилия И. О.» с полным в подсказке,
«Не назначен» вместо «— не назначен —», полный текст описания в подсказке,
`<colgroup>`) остаются и работают на прежних стилях.
