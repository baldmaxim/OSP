# API реестра расценок ОСП — инструкция для смежных отделов

Доступ **только на чтение** к двум вкладкам реестра расценок портала ОСП (`https://tender.su10.ru/rates-registry`):

| Вкладка на портале | Адрес API | Что внутри | Когда обновляется |
|---|---|---|---|
| Расценки от подрядчиков (КП) | `/api/rates/kp` | цены подрядчиков из КП по тендерам ОСП (материалы и работы) | пересчёт реестра — раз в 10 минут |
| Договорные расценки (Larix) | `/api/rates/larix` | цены материалов и работ из ВОР договоров в Larix.CPM | раз в день, после 05:00 по Москве; время загрузки — поле `loaded_at` |

Записывать, менять и удалять через API нельзя. Входить на портал не нужно — доступ по ключу.

## 1. Ключ доступа

- Ключ выдаёт администратор портала ОСП — отдельный на каждый отдел или систему. Ключ открывает только те
  вкладки, которые для него согласованы.
- Ключ — как пароль: не пересылайте его в общих чатах и письмах, не вставляйте в код, который лежит в общем
  доступе. Потеряли или есть подозрение, что ключ видел посторонний, — сообщите администратору: старый ключ
  отключат, выдадут новый.
- Передавайте ключ в заголовке **`X-API-Key: <ключ>`**. Если программа не умеет задавать заголовки (простой
  импорт в Excel), можно параметром `?key=<ключ>`, но такой адрес остаётся в истории браузера и в файлах
  запросов — при первой возможности переходите на заголовок.
- Только HTTPS. Запрос по `http://` получит отказ 403.

**Проверка ключа:**

```bash
curl -H "X-API-Key: <ключ>" https://tender.su10.ru/api/rates/health
```

Ответ `{"ok":true,"resources":["kp","larix"]}` — ключ рабочий, в `resources` — вкладки, открытые этому ключу.

## 2. Как устроен запрос

`GET https://tender.su10.ru/api/rates/<ресурс>?<параметры>`

Общие параметры (все необязательные):

| Параметр | Значение |
|---|---|
| `limit` | строк в ответе: от 1 до 1000, по умолчанию 500 |
| `offset` | сколько строк пропустить (для постраничной выгрузки), по умолчанию 0 |
| `search` | подстрока в наименовании позиции, без учёта регистра: `search=бетон` |
| `type` | `material` — материалы, `work` — работы |
| `price_min`, `price_max` | цена за единицу от и до, число с точкой: `price_min=100.5` |
| `date_from`, `date_to` | дата в виде `ГГГГ-ММ-ДД`, границы включительно (у КП — дата КП, у Larix — дата договора) |
| `format` | `json` (по умолчанию) или `csv` |

Параметры можно сочетать, условия складываются через «И». Строки всегда отсортированы по наименованию.

**Ответ JSON:**

```json
{ "rows": [ … ], "limit": 500, "offset": 0, "count": 1234, "has_more": true }
```

- `rows` — строки (поля — ниже, отдельно для каждого ресурса);
- `count` — сколько всего строк подходит под условия; может прийти `null`, если подсчёт не успел, — строки при
  этом верные, просто листайте до `has_more: false`;
- `has_more` — есть ли следующая страница: тогда повторите запрос с `offset`, увеличенным на `limit`;
- у `larix` дополнительно `loaded_at` — когда данные последний раз загружены из Larix (UTC, ISO 8601).

**Ответ CSV** (`format=csv`): кодировка UTF-8 с BOM, разделитель «;» — Excel с русскими настройками открывает
файл сразу. Первая строка — названия полей. В CSV приходит одна страница (не больше 1000 строк); для полной
выгрузки листайте `offset` или берите JSON (раздел 5).

## 3. Расценки от подрядчиков (КП) — `/api/rates/kp`

Одна строка — цена одного подрядчика по одной позиции в одном тендере (вид + наименование + единица измерения).
Если подрядчик подавал КП несколько раз, в реестре — последняя цена.

| Поле | Что это |
|---|---|
| `id` | постоянный номер строки (тендер + подрядчик + вид + позиция); удобен для сверки между выгрузками |
| `item_type` | `material` — материал, `work` — работа |
| `item_name` | наименование позиции |
| `unit` | единица измерения |
| `price` | цена за единицу, руб., как в КП подрядчика |
| `proposal_date` | дата КП |
| `counterparty_id`, `counterparty_name` | подрядчик |
| `tender_id`, `tender_desc` | тендер ОСП и его описание |
| `object_id`, `object_name` | объект строительства |

Дополнительные отборы: `counterparty=<counterparty_id>`, `object=<object_id>`, `tender=<tender_id>` — значения
берутся из полей уже полученных строк.

```bash
curl -H "X-API-Key: <ключ>" \
  "https://tender.su10.ru/api/rates/kp?type=material&search=бетон&date_from=2026-01-01&limit=1000"
```

## 4. Договорные расценки (Larix) — `/api/rates/larix`

Одна строка — позиция ВОР договора в Larix.CPM с ценой материалов и ценой работ. Одинаковые строки ВОР
(тот же договор, позиция, единица и цены) сведены в одну, их число — в `repeats`.

| Поле | Что это |
|---|---|
| `id` | номер строки — **меняется при каждой ежедневной загрузке**, для сверки между днями не годится |
| `item_name`, `unit` | наименование позиции и единица измерения |
| `price_material` | цена материалов за единицу, руб.; `null` — цены материалов в договоре нет |
| `price_work` | цена работ за единицу, руб.; `null` — цены работ нет |
| `vat_rate` | ставка НДС, если Larix её передаёт (сейчас не передаёт — `null`) |
| `materials_used`, `comment` | применяемые материалы и комментарий из ВОР |
| `project_id`, `project_name` | проект (объект) в Larix |
| `contractor_id`, `contractor_name` | подрядчик |
| `contract_id`, `contract_number`, `contract_date` | договор в Larix: номер, дата (`ГГГГ-ММ-ДД`); карточка — `https://cpm.su10.larix.ru/contract/<contract_id>` |
| `contract_state` | статус договора в Larix (например, «Заключен», «Закрыт») |
| `object_type` | вид документа (например, «Договор», «ДС») |
| `osp_contract_id` | номер договора в портале ОСП, если договор там заведён со ссылкой на Larix; иначе `null` |
| `repeats` | сколько одинаковых строк ВОР сведено в эту |

Особенности отборов:

- `type=material` — только строки с ценой материалов, `price_min` / `price_max` — по ней; `type=work` — так же по
  цене работ; без `type` — строки, где **любая** из двух цен попадает в пределы;
- `project`, `contractor`, `contract` — номера Larix (поля `project_id`, `contractor_id`, `contract_id`), можно
  несколько через запятую: `contractor=33,34`;
- `state` — статус договора, можно повторить: `state=Заключен&state=Закрыт`;
- `date_from` / `date_to` — по дате договора.

```bash
curl -H "X-API-Key: <ключ>" \
  "https://tender.su10.ru/api/rates/larix?type=work&search=перегород&price_max=3000&limit=1000"
```

Загрузка из Larix идёт рано утром по Москве (обычно до 06:00). Полную выгрузку Larix делайте после этого — иначе
часть страниц придёт из прежней загрузки, часть из новой. Сверяйте `loaded_at` первой и последней страницы.

## 5. Выгрузить всё

Одна страница — не больше 1000 строк. Чтобы получить весь реестр, запрашивайте страницы по очереди
(`offset` = 0, 1000, 2000, …) до `has_more: false`, с паузой 1 секунда между запросами (ограничения — раздел 6).
Договорных расценок Larix около 72 тыс. строк — это примерно 75 запросов, полторы минуты.

**Python:**

```python
import os
import time
import requests

BASE = "https://tender.su10.ru/api/rates"
KEY = os.environ["OSP_RATES_KEY"]  # ключ — из переменной окружения, не в тексте программы


def fetch_all(resource, **filters):
    rows, offset = [], 0
    while True:
        r = requests.get(f"{BASE}/{resource}", headers={"X-API-Key": KEY},
                         params={**filters, "limit": 1000, "offset": offset}, timeout=120)
        if r.status_code in (429, 503):  # лимит или сервис занят — подождать и повторить ту же страницу
            time.sleep(10)
            continue
        r.raise_for_status()
        page = r.json()
        rows += page["rows"]
        if not page["has_more"]:
            return rows
        offset += 1000
        time.sleep(1)


larix = fetch_all("larix")
kp_materials = fetch_all("kp", type="material", date_from="2026-01-01")
```

**Excel (Power Query), весь реестр в таблицу.** «Данные → Получить данные → Из других источников → Пустой
запрос» → «Расширенный редактор», вставить текст, указать ключ и ресурс. Если Excel спросит способ входа для
`https://tender.su10.ru/` — выбрать «Анонимно».

```
let
    Key = "ВСТАВЬТЕ_КЛЮЧ",
    Resource = "larix",          // или "kp"
    PageSize = 1000,
    GetPage = (offset as number) =>
        Function.InvokeAfter(
            () => Json.Document(Web.Contents("https://tender.su10.ru/api/rates/",
                [RelativePath = Resource,
                 Query = [limit = Text.From(PageSize), offset = Text.From(offset)],
                 Headers = [#"X-API-Key" = Key]])),
            #duration(0, 0, 0, 1)),
    Pages = List.Generate(
        () => [o = 0, p = GetPage(0)],
        each [p] <> null,
        each if [p][has_more] then [o = [o] + PageSize, p = GetPage([o] + PageSize)] else [o = [o], p = null],
        each [p][rows]),
    Result = Table.FromRecords(List.Combine(Pages), null, MissingField.UseNull)
in
    Result
```

Отборы добавляются в `Query`, например `Query = [limit = …, offset = …, type = "material", search = "бетон"]`.
Ключ в файле Excel виден каждому, кто откроет запрос, — не рассылайте такую книгу.

**Excel, быстрый запрос одной страницы** (до 1000 строк): «Данные → Из Интернета», адрес

```
https://tender.su10.ru/api/rates/kp?key=<ключ>&format=csv&limit=1000&search=бетон
```

## 6. Ограничения

- не больше **60 запросов в минуту** и **2 одновременных** запросов на один ключ; сверх — ответ 429, подождите и
  повторите;
- `limit` больше 1000 сервер сам уменьшает до 1000;
- ответы не кешируются: каждый запрос — свежие данные.

## 7. Ошибки

Тело ответа с ошибкой — `{"error": "текст"}`.

| Код | Причина | Что делать |
|---|---|---|
| 400 | неверный параметр (дата не `ГГГГ-ММ-ДД`, номера Larix не числами) | исправить запрос по тексту ошибки |
| 401 | нет ключа или ключ неверный / отключён | проверить ключ; не помогло — к администратору |
| 403 | ключу не открыт этот ресурс, или запрос по `http://` | запросить доступ у администратора; использовать `https://` |
| 404 | неизвестный ресурс | доступны `kp`, `larix` (и `supply`, если открыт) |
| 429 | превышен лимит запросов | пауза 10–60 секунд и повтор |
| 500, 503 | сбой или работы на сервере | повторить позже; повторяется — к администратору ОСП |
